# Sample Usage

## 1. prompt_agent.md (generate PRP files)
Please generate the Core Features section PRP files following the requirements given in prompt_agent.md.

### Notes
- You must be in Agent mode using GPT5-Codex
- You must reference `prompt_agent.md` FIRST, then `00-core-prp.md`, and finally the `README.md` file for writing the PRP file.

## 2. architect_agent.md (review PRP files)
Please review and update the PRP files given following the requirements in architect_agent.md.

### Notes
- You must be in Agent mode using GPT5-Codex
- You must reference `architect_agent.md` FIRST, then the `PRPs` folder, finally the `EVALUATION.md` file for reviewing and updating the PRP files.

## 3. review_agent.md (final review of PRP files)
Please read the `README.md` given carefully without executing, pay attention to PRP Structure section, Related Documentation section, Technical Stack Reference Section, Tips for AI Assistants section, and Contributing sections.
Then, review and update the PRP files by strictly following the relevant instructions in `README.md` given.

### Notes
- You must be in Agent mode using GPT5-Codex
- You must reference the `README.md` file, and then the `PRPs` folder for reviewing and updating the PRP files.
